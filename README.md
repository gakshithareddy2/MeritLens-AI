# MeritLens AI — See Beyond the Score 🎓

## 📌 About the Project

**MeritLens AI** is an AI-powered student performance analysis and learning support platform. It helps teachers understand student performance and helps students identify what they need to improve.

Instead of focusing only on marks, MeritLens AI considers factors such as attendance, assignments, assessment scores, and study progress to provide useful insights and personalized study recommendations.

## 🎯 Objectives

- Analyze student academic performance.
- Help teachers identify students who may need extra support.
- Provide personalized study tips and practice tasks.
- Track student progress, study goals, and achievements.
- Display academic information through interactive dashboards.
- Encourage better learning habits and continuous improvement.

## ✨ Key Features

### 👩‍🏫 Teacher Dashboard
- View the total number of students.
- Monitor average marks and attendance.
- Analyze subject-wise performance.
- Identify students who may need additional support.
- View performance summaries and insights.

### 👨‍🎓 Student Dashboard
- View marks, attendance, and assignment completion.
- Identify strengths and areas for improvement.
- Receive personalized study recommendations.
- Create study goals and weekly study plans.
- Track progress through charts and progress indicators.

### 🤖 AI-Powered Analysis
- Analyze academic performance data.
- Identify performance patterns and potential learning risks.
- Support personalized study recommendations.
- Provide AI-assisted explanations where the feature is configured.

## 🔄 How It Works

1. **Login:** Teachers and students access their respective dashboards.
2. **Data Collection:** The system uses student marks, attendance, and assignment information.
3. **Performance Analysis:** The system analyzes the available academic data.
4. **Recommendations:** Students receive study suggestions and practice tasks.
5. **Progress Tracking:** Students monitor their study goals and improvement.
6. **Insights:** Teachers and students review performance through dashboards and reports.

## 🚀 Getting Started

### Prerequisites

Install the following software before running the project:

- Node.js and npm
- Git
- Python, if required by the machine learning module

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

**2. Open the project folder**

```bash
cd <YOUR_PROJECT_FOLDER>
```

**3. Install frontend dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal, commonly `http://localhost:5173`.

*Run the backend and machine learning services separately if your project has them. Follow the instructions in their respective folders.*
