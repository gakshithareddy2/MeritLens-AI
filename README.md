# MeritLens AI

AI-powered student performance analysis platform.

## Overview

MeritLens AI is a software project intended to support student performance analysis and learning insights.

## Project Structure

The application source code is located in `meritlens_dynamic_work/meritlens_contrast_fix/`.

- `src/` — frontend source files
- `server/` — server-side application files
- `ml/` — machine learning-related files
- `tests/` — test files
- `README.md` — project documentation

## Prerequisites

- Node.js and npm
- Python, if required by the machine learning or backend components

## Getting Started

1. Clone the repository.
2. Navigate to the application folder.
3. Install the dependencies according to the project's setup instructions.
4. Configure environment variables using `.env.example`, if required.
5. Start the application using the scripts documented in the application package configuration.

## Development Workflow

This project uses Git and GitHub for version control.

- `main` — primary branch
- Feature branches — isolated development work
- Pull requests — review changes before merging

## Security

Never commit passwords, API keys, access tokens, private datasets, or `.env` files.
